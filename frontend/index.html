Penyimpanan Fisik DICOM & Modality
Direktori fisik di komputer Windows Host.
/storage/dicom
SIMDUDIM_STORE di port 11112
SIMDUDIM di port 104
Cara Mengubah Folder Penyimpanan:
  1. Buka file .env di folder utama server Anda.
  2. Cari baris LOCAL_DICOM_STORAGE_PATH.
  3. Ubah nilainya ke folder pilihan Anda (contoh: E:/penyimpanan_dicom).
  4. Jalankan perintah berikut di PowerShell untuk merestart kontainer: 
    docker compose down
docker compose up -d
